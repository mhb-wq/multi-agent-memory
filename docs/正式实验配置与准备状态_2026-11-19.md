# GateMem 正式实验：配置与准备状态

更新时间：2026-11-19。用户已明确：**不进行试运行**。此前已完成的单点接口检查仅用于排错，不是实验结果；这一决定之后没有再发出模型测试请求。

## 已确定

- 数据集：GateMem，91 个 episode、2,218 个 checkpoint，覆盖 medical、office、education、household 四个领域。
- 九个基线：NaiveRAG、BM25、Mem0、A-MEM、MemGPT、LightMem、MemoryBank、DG-Mem、EGMemory。
- 模型组：DeepSeek V4.1 Flash、GPT-5.6-sol、GLM-5.3。每组使用该组同一个模型负责记忆写入、回答和判分；向量始终使用本地 `sentence-transformers/all-MiniLM-L6-v2`，384 维。
- 同一模型组内比较基线；跨模型组的分数可能同时反映模型差异和裁判尺度差异，应在报告中说明。不同裁判也不应被当成同一个测量仪器。
- 中转地址使用 `https://api.ciyuan.fast/v1`，模型目录为其 `/models`。密钥已保存在 GateMem 本地 `.env`（Git 忽略），不写入代码、清单或调用记录。

## 剩余问题与正式启动条件

1. 用户正在确认：请求 `deepseek-v4.1-flash` 时，中转站有时返回 `deepseek-flash`，有时返回完整名称。在一次 MemGPT 单点调用中，同一组请求出现了两种返回名。不能仅凭返回名推断两者是同一个实际模型，也不能在确认前宣称同组使用了同一模型。
2. 当前密钥只处于 DeepSeek 分组；切到 GPT 和 GLM 分组后，还需核对目录中**精确模型 ID**和是否支持工具调用。当前尚不能验证或运行另外两组。
3. 各系统需冻结适配版本、提示词、模型参数、数据边界及资源预算，并让我们的系统与基线使用相同的数据、向量和对应组的模型。当前启动器默认 `top_k=20`、回答温度 0.2、裁判温度 0、单 episode 串行；这些是当前程序参数，尚未宣称经过最终实验方案确认。EGMemory 原生工具调用会自行决定检索次数和条数，不能简单视为受统一 top-k 20 约束；各基线内部写入温度和处理机制也可能不同，需要记录而不是默认等同。
4. 上游及本地适配仍存在需要报告的差异：MemoryBank 多人增量改写、MemGPT 重实现、EGMemory 存储/重排替换、LightMem 检查点更新，以及模型调用失败、截断和长对话状态问题。不得把单点接口成功当作完整复现或最终实验成功。
5. 精确费用和运行时间尚无法仅凭单点估算。用户明确不进行试运行，因此不再为估价新增试验调用；大规模正式运行仍需确保余额和失败后的可恢复方案。按 9 基线 × 3 模型 × 2,218 checkpoint 就有 59,886 次基线问答检查点，另有记忆写入、工具调用和裁判调用；我们的方法另计。

## 本地文件和审计

- `GateMem/scripts/run_relay_experiment.py` 是逐基线、逐领域运行入口；每次读取本地 `.env`，将同一模型 ID 用于写入、回答、判分。中转 API 用 chat-completions，避免将 OpenAI Responses 协议误发给不兼容的代理。
- `GateMem/scripts/local_embedding_server.py` 仅监听本机，为需要 OpenAI 格式 embedding 的基线提供本地 MiniLM 384 维向量；本地 embedding token 未计数，不能把其记录中的 0 解释为真实 token 成本。
- `GateMem/scripts/local_relay_proxy.py` 仅监听本机，拒绝请求其他模型，并记录请求模型、接口返回模型、token usage、HTTP 状态和结束原因，不记录密钥或提示内容。接口返回截断或空结果时按错误处理，避免直接把不完整回复当成正常回答。旧的单点检查发生在此审计功能之前，不能补录它们未保存的内部调用。
- DG-Mem 重排模型版本 `233902d25c440f23af6f7d6e94d2946bac0bee0a`；`model.safetensors` SHA-256 `821d1aa69520101d6e0737f78a042ae25b19e5cb9160701909d10434f4aeb0ae` 与下载源记录一致。其余基线来源和固定提交见 `基线清单与获取记录.md`。
- 代码检查：19 项离线测试通过，覆盖接口、时间边界、重置、状态延续、可选图功能、临时数据库关闭，以及中转调用记录不包含密钥和提示内容。测试并不证明实验结果质量。
