# GateMem 实验基线：代码获取记录

整理日期：2026-11-19。本目录用于保存上游原始代码和后续基线接入所需的参照；代码已获取不等于已经完成 GateMem 适配或复现论文结果。

## 选定的九个基线

| 基线 | 本地来源及建议起点 | 当前状态 |
| --- | --- | --- |
| NaiveRAG | `GateMem/bench/agents/rag_naive.py`；另有 `MemSyco-Bench/baselines/naive_rag.py` | GateMem 有适配版。须显式固定检索后端：该代码默认 TF-IDF，也支持 embedding。 |
| BM25 | `DG-Mem/src/bm25.py` | 已有独立 BM25 检索实现，但尚未作为独立 GateMem agent 接入；不是将 TF-IDF 当作 BM25。 |
| Mem0 | `GateMem/bench/agents/mem0.py`、`GateMem/third_party/mem0_upstream/`；`MemSyco-Bench/baselines/memzero.py` | GateMem 提供 builtin 和 vendored upstream 两种后端。MemSyco 的 MemZero 基于 Mem0，但具体版本和行为需要与 GateMem 的后端区分。 |
| A-MEM（AMEM） | `GateMem/bench/agents/a_mem.py`；`MemSyco-Bench/baselines/amem.py` | GateMem 是基于 A-MEM 思路的 benchmark-adapted 实现，默认 heuristic 元数据；另有 LLM 模式。不可不加说明地称为官方原版。 |
| MemGPT | `MemSyco-Bench/baselines/memgpt.py` | 获取了轻量级重新实现，非原始 MemGPT/Letta 完整仓库；尚需接入 GateMem。 |
| LightMem | `MemSyco-Bench/baselines/lightmem.py`、`MemSyco-Bench/baselines/lightmem/vendor/` | 获取了基线适配层和 vendored LightMem 代码；尚需接入 GateMem。 |
| MemoryBank | `MemSyco-Bench/baselines/memorybank.py`、`MemSyco-Bench/baselines/memorybank/vendor/` | 获取了基线适配层及辅助代码；尚需接入 GateMem。 |
| DG-Mem | `DG-Mem/` | 已获取匿名仓库 ZIP 并解压。上游入口面向 GroupMemBench 和 LoCoMo，尚需接入 GateMem。 |
| EGMemory | `EGMemory/` | 已获取匿名仓库 ZIP 并解压。上游提供 `groupmem` 包及 GroupMemBench 流程，尚需接入 GateMem。 |

EvoMemState 论文结果表列出了 NaiveRAG、MemGPT、MemoryBank、Mem0、A-MEM 和 LightMem，但此版本仓库未包含这些基线的完整实现；其代码依赖外部 MemSyco-Bench 的基线接口，因此另外获取同组织的 MemSyco-Bench。三个仓库中的同名实现不保证行为等价，正式运行应记录具体来源、配置和版本。

## GateMem 数据与适配约束

官方数据位于 `GateMem/bench/data/`，已校验 JSONL 可解析：medical 21 episodes / 579 checkpoints，office 17 / 547，education 30 / 540，household 23 / 552，共 91 / 2,218。官方 `docs/evaluation_protocol.md` 要求每个 episode 重置、按时间顺序逐步摄入，在 checkpoint 时仅使用当前可见信息，不能将隐藏标签、期望动作或泄漏目标交给被测系统。

主要指标为 Utility、Access-Control Violation、Active-Forgetting Failure、Over-Refusal 和 MGS。先选定同一响应模型、嵌入模型、检索预算和提示及参数，并记录每项差异；对原生不支持删除或权限控制的系统，应明确记录实际处理方式，避免混淆原版能力和额外适配层能力。EGMemory README 明示其服务删除接口为 501、存储为 append-only，必须在遗忘实验设计中单独说明。

## 本次验证

- 两个 ZIP 均通过压缩完整性检查，并在路径校验后解压。
- GateMem 的 `python bench/scripts/run_eval.py --help` 成功显示官方 agent 和配置选项；尚未执行模型推理或正式评测。
- EGMemory 使用本机已有 `numpy` / `rank-bm25`，设置 `PYTHONPATH` 后运行 `examples/offline_smoke.py`，结果为 `VERDICT: OK`；这不验证真实 LLM 或数据库。
- DG-Mem 的 `BM25Retriever` 使用三条示例文本检索，正确返回目标文本；未运行 DG-Mem 完整流程。
- 本机默认 Python 为 3.10.11；DG-Mem README 要求 Python 3.11 或更新版本。未安装或修改全局依赖，未配置模型密钥、下载模型权重或运行正式实验。
