# 共享记忆池实验模式

此模式用于研究 Card—State—Sleep，不用于声称访问控制或主动遗忘已经实现。

## 模式与边界

`control.access_mode` 接受 `shared_pool` 或 `governed`，默认底层为 `governed`；共享模式关闭用户/Agent的按主体、类别授权过滤，并禁用结构化授权、撤权和删除。保留原有权限规则与接口；禁用模式不是删除代码。身份、空间、Agent 和其基本读写职责仍验证，场景之间不共享记忆。标记删除/阻断的已有存储仍不可被当成正常卡片。

共享模式对直接卡片只提供当前消息，允许一个消息产生多张卡；subject需要当前消息中可核对的显式线索或说话人的第一人称表达，否则保留原话、subject=null且不更新个人状态。该规则是保守的词面检查，不证明模型对句子关系的语义判断正确。

GateMem 回放按所有成功处理的输入消息计数，每20条进行内部Sleep，问答不额外触发。GroupMemBench主回放和诊断回放，以及调用后者的PERMA诊断路径采用同样频率；不足20条的末尾不会被暗中提前整理。Sleep可维护当前空间内不同主体的相关卡，不向Agent公开完整State。

2026-10-29 修正：此前“按全空间跨主体语义得分取候选”的描述与实现不一致；旧实现仍分库搜索，用组内 reciprocal-rank 分数合并，会挤掉相关证据。新版每个空间/场景只用一个公共 MemCube/Qdrant collection（`stable_id("shared_pool", space_id)`），所有用户、类别的卡片进入同一索引，身份/类别仅保留为元数据。检索只调用一次原生 `GeneralTextMemory.search(query, top_k)`，保留原生顺序，不做分组配额、跨库名次合并、State 证据插队或来源扩展。传入 subject_ids 不限制共享池搜索；State 与说明模型只能提供注释，不能删减、替换或重排 top-k。与 MemOS 原生基线对齐的是公共索引和搜索接口，不代表各系统的记忆抽取及全部原生算法相同。

公共池仍按空间/场景隔离，避免不同实验样本串记忆。旧分库运行目录不能直接续跑；新版明确报错，必须在新目录从原始消息重建，不会自动改写旧实验数据。Sleep 在共享模式下只对全空间维护一次，不再逐人重复维护。

正常检索输出及空检索情况下，GateMem均调用官方问答模板；官方评审和指标不变，模型和向量模型按既定替换。

GateMem `run_gatemem.py --system ours` 默认shared_pool；可显式 `--ours-mode governed` 使用旧控制路径。GroupMemBench新建run配置标记 `access_mode=shared_pool`；旧受保护运行的代码哈希校验不应绕过。禁止把共享模式指标称为权限模块或主动遗忘功能的成绩。

未调用线上模型或重跑数据集；已有实验结果、统计文件不被更新。语言模型产生的主体、State、自由使用说明仍可能语义错误，程序基础检查并不能保证正确。权限模式仍有先前记录的不足，切换模式本身不能修复它。
